📊 Power BI Project

Project Name: Optimizing IT Support Team Performance Using Analytics

Description:
This project focuses on analyzing the performance of an internal IT Helpdesk team using Power BI. The dataset contains ticket-level data including issue category, priority, severity, resolution time, and satisfaction score. The objective is to derive actionable insights to improve operational efficiency and service quality.

Repository Link:
https://github.com/BalajiSK05/Optimizing-IT-Support-Team-Performance-Using-Analytics

Live Dashboard:
Dashboard developed using Power BI Desktop

Project Detailed Description:

This project includes:

- Data cleaning and transformation using Power Query
- Data modeling and relationship handling
- DAX measures for KPI calculations
- Performance dashboards including:
  - Ticket Overview Dashboard
  - Ticket Distribution Dashboard
  - Satisfaction & Resolution Analysis Dashboard
- KPI analysis such as:
  - Total Tickets
  - High Priority %
  - Unassigned Tickets
  - Average Resolution Time
  - Average Satisfaction Score

The dashboards help identify bottlenecks, workload distribution, priority handling efficiency, and satisfaction trends.
